# Contributing

Thanks for your interest in GitBeat. Improvements are welcome.

- By contributing, you agree that your contribution is licensed under the
  **GNU GPL v3** with the additional attribution term in [`NOTICE`](NOTICE), the
  same license as the rest of the project.
- Keep the author attribution to Jason Mello (the "About" screen and the README)
  intact. See [`NOTICE`](NOTICE).
- The **name, logo and mascot are not part of the license.** Don't reuse them in
  a fork; pick your own name and artwork (again, [`NOTICE`](NOTICE)).
- Before changing the UI or any on-screen text, read [`DESIGN.md`](DESIGN.md).
  The project map for the rest is [`AGENTS.md`](AGENTS.md).
- Run the project checks before opening a PR: `swift run GitBeatChecks`.
